# Project Hail Mary 🚀
A privacy-first, FOSS, Markdown-native personal productivity dashboard inspired by UseMemos.

## Stack
- Backend: Go (Golang) for lightning-fast, lightweight performance on tiny servers.
- Frontend: Single-page HTML/Tailwind/JS (or embedded React components) styled just like UseMemos.
- Storage: Plain text Markdown (`.md`) files. No vendor lock-in.

## Features
- Quick capture notes & diary
- Kanban/Flow board for tasks
- Habit tracking & Pomodoro
